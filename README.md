# Maturitní projekt – Online Autobazar

Tento projekt je součástí maturitní práce a jeho cílem je vytvořit moderní webovou aplikaci pro online autobazar.  
Aplikace umožní prohlížet, přidávat a spravovat nabídky automobilů pomocí jednoduchého uživatelského rozhraní a REST API.

---

## 🧩 Použité technologie

### **Frontend**
- **HTML**
- **CSS**
- **Tailwind**
- **Bootstrap**
- **GSAP**
- **Javascript**  

### **Backend**
- **Python**
- **MYSQL**

### **Další nástroje**
- **Git + GitHub** – verzování a spolupráce
